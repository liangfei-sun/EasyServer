# 快速入门指南

## 系统架构概述

EasyServer 是一个面向个人用户的一站式服务器部署方案。只需一台 Ubuntu 机器，通过 Web 界面即可完成所有服务的安装、配置和管理。

### 核心组件

| 组件 | 说明 |
|------|------|
| **管理引擎** | Python FastAPI 后端 + Vue 3 前端，提供 Web 管理界面 |
| **模块系统** | 每个服务独立为模块，按需安装，互不影响 |
| **Nginx 反代** | 统一的域名路由和 SSL 终止 |
| **Docker** | 所有服务以容器方式运行，隔离且易于管理 |

### 架构图

```
用户浏览器
    ↓
Nginx（反向代理 + SSL）
    ├── → 管理引擎（:9800）
    ├── → Uptime Kuma（:3001）
    ├── → Jellyfin（:8096）
    ├── → Joplin（:22300）
    └── → 其他服务...
```

## 访问方式

EasyServer 支持两种外网访问方式：

### 方式一：域名反代（推荐）

通过自己的域名 + SSL 证书访问各服务，格式为 `子域名.你的域名:端口`。

- 优点：统一的域名入口，HTTPS 加密，专业美观
- 需要：自己的域名 + DNS 配置 + SSL 证书

### 方式二：IPv6 直连

通过服务器的 IPv6 地址 + 端口直接访问各服务。

- 优点：无需域名，配置简单
- 缺点：需记住各服务端口，无 SSL 加密

## 管理面板功能

### 仪表盘

系统总览页面，展示：
- 服务器资源使用情况（CPU、内存、磁盘）
- 各服务运行状态一览
- 快速操作入口

### 服务管理

- 查看所有已安装服务的状态
- 启动、停止、重启、更新服务
- 查看服务日志

### 模块市场

- 浏览所有可用服务模块
- 一键安装新服务，填写配置表单
- 卸载不需要的服务

### 全局设置

- 域名配置
- 访问模式切换（域名/IPv6/混合）
- SSL 证书管理
- Nginx 配置生成

## 首次配置流程

### 第一步：系统安装

1. 在 Ubuntu 服务器上克隆项目
2. 运行安装脚本 `bash scripts/install.sh`
3. 等待 Docker 和依赖安装完成

### 第二步：启动管理引擎

```bash
cd ~/easyserver
docker compose up -d
```

### 第三步：访问管理面板

- 本地访问：`http://localhost:9800`
- 外网访问：根据你的网络配置选择域名或 IPv6

### 第四步：完成初始化向导

首次进入会弹出安装向导，引导你：
1. 设置管理员密码
2. 配置域名信息（如果使用域名模式）
3. 安装基础服务模块

### 第五步：安装服务

1. 进入「模块市场」页面
2. 选择需要的服务（如 Nginx、Uptime Kuma 等）
3. 填写配置参数
4. 点击安装

### 第六步：配置外网访问

根据选择的访问方式：
- **域名模式**：配置 DNS 解析 → 安装 ACME 证书 → 生成 Nginx 配置
- **IPv6 直连**：在各服务中直接使用端口访问

详细配置步骤请参阅 [网络配置指南](/docs/network-config)。
