# 快速入门指南

## 系统架构概述

EasyServer 是一个面向个人用户的一站式服务器部署方案。只需一台 Ubuntu 机器，通过 Web 界面即可完成所有服务的安装、配置和管理。

### 核心组件

| 组件 | 说明 |
|------|------|
| **管理引擎** | Python FastAPI 后端 + Vue 3 前端，提供 Web 管理界面 |
| **模块系统** | 每个服务独立为模块，默认均不安装，按需安装，互不影响 |
| **Nginx 反代** | 可选模块：统一的域名路由和 SSL 终止（配置网络时自动安装） |
| **Docker** | 所有服务以容器方式运行，隔离且易于管理 |

> **注**：EasyServer 安装时不安装任何服务模块，Nginx、ACME、DDNS、Cloudflare Tunnel 等均为可选模块，默认不安装。

### 架构图

```
用户浏览器
    ↓
Nginx（反向代理 + SSL，可选模块）
    ├── → 管理引擎（:9800）
    ├── → Uptime Kuma（:3001）
    ├── → Jellyfin（:8096）
    ├── → Joplin（:22300）
    └── → 其他服务...
```

## 访问方式

EasyServer 支持两种外网访问方式：

### 方式一：域名反代（推荐）

通过自己的域名 + SSL 证书访问各服务，格式为 `子域名.你的域名:端口`。

- 优点：统一的域名入口，HTTPS 加密，专业美观
- 支持阿里云和 Cloudflare 两种 DNS 提供商
- 需要：自己的域名 + DNS 配置 + SSL 证书

### 方式二：Cloudflare Tunnel

通过 Cloudflare 隧道穿透访问，无需公网 IP 和开放端口。

- 优点：无需公网 IP，无需端口转发，自带 SSL
- 缺点：流量经过 Cloudflare，需 Cloudflare 账号

### 方式三：IPv6 直连

通过服务器的 IPv6 地址 + 端口直接访问各服务。

- 优点：无需域名，配置简单
- 缺点：需记住各服务端口，无 SSL 加密，客户端需 IPv6 网络

## 管理面板功能

### 仪表盘

系统总览页面，展示：
- 服务器资源使用情况（CPU、内存、磁盘）
- 各服务运行状态一览
- 快速操作入口

### 服务管理

- 查看所有已安装服务的状态
- 启动、停止、重启、更新服务
- 查看服务日志

### 应用商店

- 浏览所有可用服务模块
- 一键安装新服务，填写配置表单（密码类字段可一键随机生成）
- 安装采用后台任务执行，可实时查看拉取镜像进度；失败时直接提示原因（如无法连接 ghcr.io / Docker Hub）
- 卸载不需要的服务：卸载会停止容器并删除镜像，可在确认弹窗中选择保留或删除该模块的数据目录

### 全局设置

- 域名配置
- 访问模式切换（域名/IPv6/混合）
- SSL 证书管理
- Nginx 配置生成

## 首次配置流程

### 第一步：系统安装

1. 在 Ubuntu 服务器上克隆项目
2. 运行安装脚本 `bash scripts/install.sh`
3. 等待 Docker 和依赖安装完成

### 第二步：启动管理引擎

```bash
cd ~/easyserver
docker compose up -d
```

### 第三步：访问管理面板

- 本地访问：`http://localhost:9800`
- 外网访问：根据你的网络配置选择域名或 IPv6

### 第四步：完成初始化向导

首次进入会弹出极简安装向导，引导你：
1. 填写域名和 SSL 邮箱
2. 设置管理员密码
3. 完成基础配置（默认不安装任何服务）

### 第五步：配置网络

安装完成后，进入「网络配置」页面，系统会根据你的环境智能推荐访问方式：

- **Cloudflare Tunnel（推荐）**：无需公网 IP，免端口，域名托管在 Cloudflare 即可一键接入
- **域名反代（Nginx）**：需开放端口（如 8443），域名解析到服务器 IP，DNS 记录可自动同步
- **IPv6 直连**（高级选项）：直接通过公网 IPv6 地址 + 端口访问，无需域名
- **自由配置**（高级选项）：不自动管理模块，自行从应用商店安装配置

> 选择访问方式并确认后，系统会自动安装对应网络模块：域名反代 → Nginx / ACME / DDNS，隧道 → Cloudflare Tunnel。

也可跳过，稍后在「网络配置」页面中配置。

### 第六步：安装更多服务

除网络配置时自动安装的模块外，其余服务均从「应用商店」按需安装：

1. 进入「应用商店」页面
2. 搜索或筛选需要的服务
3. 填写配置参数
4. 点击安装

### 第七步：配置备份（可选）

进入「备份中心」，配置：
- 备份周期和保留天数
- 云端备份存储（阿里云 OSS / S3 / B2）
- 查看本地备份仓库位置
